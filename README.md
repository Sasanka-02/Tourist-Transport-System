# 🧭 Tourist Transport Management System

A smart, AI-powered web application for managing tourist transport bookings in Sri Lanka. Built with Spring Boot and React.js, this system supports secure user registration, trip booking, payment processing, smart trip suggestions, and predictive analytics using real SLTDA data to assist tour guides.

---

## 📌 Features

- ✨ **User Management**
  - Tourist, Admin, and Tour Guide role-based access
  - Registration, login, profile update, password recovery
  - Admin-generated user reports

- 🚌 **Trip Booking Management**
  - Book, modify, cancel, and view trips
  - Real-time availability and booking history

- 💳 **Payment Management**
  - Secure invoice generation, payment confirmation
  - Admin dashboard for transaction monitoring

- 🤖 **Smart Trip Suggestions**
  - Personalized travel recommendations
  - Based on user history and preferences

- 📊 **Tour Guide Predictive Analytics**
  - Analysis of 2 years of SLTDA data
  - Forecast future tourist trends (e.g., peak months, top destinations, countries of origin)
  - Visual insights to assist tour planning
